# lab

PyVISA carries text commands to instruments on GPIB, USB, serial ports and the network; PyMeasure and QCoDeS add drivers and measurement records. pylablib, Harvester, Micro-Manager and python-seabreeze reach cameras, stages and spectrometers through their SDKs; NI-DAQmx acquires and generates signals; Bluesky runs plans on declared devices; slmsuite connects spatial light modulators and cameras; LabVIEW exposes its automation server. Use the selected library's discovery mechanism. VISA resource discovery applies to VISA instruments, not every camera or stage.

Reuse an existing instrument controller. If [IOP](https://github.com/EnvFoundry/IOP) owns the device, call its client from the research program so operations share that controller's conditions and scheduling. Otherwise, a library `source` program runs through the same worker as a calculation. For libraries sharing a device in one Optics state directory, define a named pool with `compute_resources(pools={"spectrometer": 1})` and put `requirements={"spectrometer": 1}` on every relevant `submit_workflow` step or environment binding. Tool concurrency alone does not exclude another library, another state directory or another application.

Record the instrument model, firmware, address, settings, settling and integration times, averaging, detector range and reading timestamps. Save raw readings as they arrive; keep dark subtraction and calibrations as separate transformations. Repeated measurements estimate repeatability; calibration, drift and model assumptions contribute other uncertainty. PyVISA's packaged sweep retains raw replies after a later failure. The packaged Bluesky scan uses ophyd.sim; replace its devices and plan with those of the actual beamline before acquiring hardware data.

Run within the equipment, actions and ranges already supplied for the experiment; ask for missing settings or an expansion of that scope. Specify the agreed finish or restoration state and attempt it on completion and Python exceptions. Forced termination can prevent that code from running; recovery belongs to the owning instrument controller. Preserve partial data and report any incomplete restoration. A simulated device exercises software flow, not the instrument's physical response.

Packaged programs: `pyvisa/sweep`, `bluesky/scan`, `slmsuite/spot_array`, `scipy/resonances`; `software_details(tool, program=NAME)` describes one. Use software_details for the selected tool’s primary documentation and implementation links.
